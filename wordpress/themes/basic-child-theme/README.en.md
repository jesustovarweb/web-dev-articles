# Basic WordPress child theme

This directory contains a minimal example of a WordPress child theme intended as a starting point for custom development.

The goal of this example is not to provide a full theme, but to show the essential structure required for a functional child theme that extends a parent theme.

## What it includes

This example only contains the files required to create a basic child theme:

- `style.css`  
  The main stylesheet containing the header that defines the relationship with the parent theme.

- `functions.php`  
  Used to load the parent theme stylesheet and add additional customizations.

- `screenshot.png`  
  Optional image used by WordPress to display the theme in the admin panel.

## What it is for

This child theme can be used as a base to:

- Customize an existing theme without modifying its original code.
- Add additional styles or scripts.
- Override parent theme templates.
- Safely experiment with design or functionality changes.

## Notes

The example is intentionally simple so it can be easily understood and adapted.  
Real projects may require additional adjustments depending on the parent theme being used.
