# Tema hijo básico para WordPress

Este directorio contiene un ejemplo mínimo de tema hijo para WordPress pensado como base de partida para desarrollos personalizados.

El objetivo de este ejemplo no es ofrecer un tema completo, sino mostrar la estructura esencial que necesita un tema hijo funcional y listo para extender el tema padre.

## Qué incluye

Este ejemplo contiene únicamente los archivos necesarios para crear un tema hijo básico:

- `style.css`  
  Archivo principal del tema hijo con la cabecera que define la relación con el tema padre.

- `functions.php`  
  Archivo donde se carga la hoja de estilos del tema padre y desde el que se pueden añadir personalizaciones adicionales.

- `screenshot.png`  
  Imagen opcional que WordPress utiliza para mostrar el tema en el panel de administración.

## Para qué sirve

Este tema hijo puede utilizarse como base para:

- Personalizar un tema existente sin modificar su código original.
- Añadir estilos o scripts adicionales.
- Sobrescribir plantillas del tema padre.
- Probar cambios de diseño o funcionalidad de forma segura.

## Notas

El ejemplo es deliberadamente simple para que resulte fácil de entender y adaptar.  
Cada proyecto puede requerir ajustes adicionales dependiendo del tema padre utilizado.
