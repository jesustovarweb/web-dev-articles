# Web development examples

This repository contains curated code examples in HTML, CSS, JavaScript, PHP and MySQL, extracted from articles published on my website.

The goal is not to provide generic snippets, but to document practical solutions based on real-world development scenarios and professional experience.

## Scope

The repository includes examples related to:

- Layout and markup (HTML and CSS)
- JavaScript interactions and behaviour
- PHP scripts and backend logic
- SQL queries and database operations
- WordPress and WooCommerce customizations
- Common patterns used in frontend and backend development

Examples are organized by context and use case, not by date or article.

## Notes

Not all the code from the articles is included here.  
Only examples that remain relevant, reusable and maintainable are part of this repository.
